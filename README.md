# Tic-Tac-Toe with Minimax AI

This is a text-based implementation of Tic-Tac-Toe where a human player competes against an AI using the Minimax algorithm.

## Features

- **Minimax Algorithm**: Ensures the AI plays optimally, guaranteeing a win or draw.
- **Turn-based Console Play**: Enter your move using numbers 1–9.
- **Scoreboard**: Tracks human wins, AI wins, and draws across multiple rounds.

## How to Use

1. Open the notebook in Google Colab.
2. Run each cell to initialize and start the game.
3. Follow on-screen prompts to play.
4. Play multiple rounds and view the scoreboard.
